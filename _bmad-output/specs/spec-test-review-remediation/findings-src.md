## Folder run: advisory observations

ℹ️ `LoveNoteMessage.test.tsx:749-755`, `806-812` and `845-851` assert that no "Can't perform a React state update on an unmounted component" warning appeared. react-dom 19.3.0 no longer emits that warning, so these three memory-leak checks cannot fail. The registry has no row for this, so it is unscored, but it is effectively C3-grade.
ℹ️ Almost every `beforeEach` relies on `vi.clearAllMocks()`, which in Vitest 5.0.1 clears call history only. It never undoes `mockReturnValue`, `mockImplementation` or unconsumed `*Once` queues. That gap is the cause of all four H4 findings, and `vi.resetAllMocks()` (or `mockReset: true` in `vitest.config.ts`) would close it for the whole suite.
ℹ️ `useNetworkStatus.test.ts:321-341` "should clear timeout on unmount" asserts only its premise and relies on "passes if no errors thrown". A leaked timer raises nothing in React 19, so the behavior named in the title is untested.
ℹ️ `useRealtimeMessages.test.ts` sends stimuli through optional chaining (`subscribeCallback?.(...)` at :550, :584, :618, :632, :905, :912). If the hook stops handing over a status callback, those calls become no-ops and the negative assertions at :925-927 pass without testing anything.
ℹ️ `LoveNoteMessage.test.tsx:246-248` mocks `getSignedImageUrl` with a real 100 ms `setTimeout` that outlives the test and resolves into whichever test runs next.
ℹ️ Five local helpers (`openWith`, `openBy`, `activateHistory`, `openRemoval`, `selectFile`/`pickPhoto`/`pick`) produce most of the M5 volume. Switching them to `userEvent.setup()` clears most M5 findings at once and removes the manual `opener.focus()` workarounds.
ℹ️ The `motion/react` pass-through mock is copied into 18 files and the EventsSettings store double into 3. A shared test-support module would keep the copies consistent and shrink `EventsSettings.test.tsx` toward the H5 threshold.
ℹ️ `MessageInput.test.tsx:486` "should add newline on Shift+Enter" never presses Shift+Enter, and `backgroundSync.test.ts:360` "should preserve message event data integrity" checks no data. Both names claim more than the tests check.
ℹ️ `loveNoteImageService.test.ts:95-101` `vi.stubGlobal('import', ...)` cannot affect `import.meta.env`, so it is dead setup.
ℹ️ `ImagePreview.test.tsx` allocates 16 MB of real `ArrayBuffer`s and then overrides `size` with `defineProperty` anyway.
